# crypto-me

## Project setup
```
npm install
```

### Compiles and hot-reloads for development
```
npm run dev
```

### Compiles and minifies for production
```
npm run build
```

### Lints and fixes files
```
npm run lint
```

### Customize configuration
Edit `vite.config.mjs` for build and development settings.

### Deployment

Merging to `main` runs the GitHub Pages workflow and publishes the Vite build at
https://pierce403.github.io/crypto.me-ng/. The relative asset base in
`vite.config.mjs` supports this repository subpath.
